## What it is

LuneBlox is [Lune](https://github.com/lune-org/lune) with the [Luau](https://luau-lang.org) underneath
changed. It keeps Lune's whole interface: the same `@lune/*` libraries, the same task scheduler, the
same Roblox datatypes and place and model files. Lune scripts run unchanged.

```sh
luneblox run script.luau
luneblox setup              # typedefs for luau-lsp, aliased as @lune
luneblox build script.luau  # a standalone executable, carrying the same Luau and flags
```

## What it changes

Lune 0.10.5 runs Luau 0.709. Roblox runs 0.740, and runs it with its own set of Luau's fast flags:
Luau ships new compiler and VM work behind flags that default to off, and Roblox turns them on
remotely. A benchmark or a test run on Lune measures a VM no game runs.

| | Lune 0.10.5 | LuneBlox |
|---|---|---|
| Luau | 0.709 | 0.740, the version Roblox runs |
| Luau's fast flags | Luau's defaults | set as the live Roblox client sets them |
| Luau's C++ built with | `-Os` | `-O3` |
| `_VERSION` | `Lune 0.10.5+709` | `LuneBlox <version>+740` |

[Why LuneBlox](/LuneBlox/guides/why-luneblox/) has the measurements, and
[Migrating from Lune](/LuneBlox/guides/migrating-from-lune/) lists what a Lune user will notice.

## A first look

```luau
local fs = require("@lune/fs")
local net = require("@lune/net")
local serde = require("@lune/serde")

local response = net.request("https://api.github.com/repos/XopoIII/LuneBlox")
local repository = serde.decode("json", response.body)

fs.writeFile("stars.txt", tostring(repository.stargazers_count))
print(_VERSION, "wrote stars.txt")
```

The [quick start](/LuneBlox/getting-started/quick-start/) walks through a first script.
