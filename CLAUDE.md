# LuneBlox - working notes

A standalone Luau runtime that runs Luau the way Roblox runs it. The binary is `luneblox`.

A hard fork of [lune-org/lune](https://github.com/lune-org/lune), maintained as `XopoIII/LuneBlox` and
released from `0.10.6` onward. MPL-2.0, like upstream, and the upstream copyright stays in LICENSE.txt.
The `README.md` says why the fork exists; `CHANGELOG.md` tells each release's story.

## Everything here is written in English

Code, comments, identifiers, documentation, commit messages, pull request bodies, agent and skill
instructions, prompts - **all of it, without exception**. `scripts/check-english.sh` runs on every
commit and rejects letters outside ASCII. Box-drawing characters and em dashes are punctuation, not
letters, and stay allowed. Test fixtures that exist to exercise Unicode are exempt by path in the script.

Conversation with the user may happen in another language; nothing that lands in the repository does.

## The tree is at zero

No clippy warnings (pedantic included), no luau-lsp diagnostics, no selene warnings, no formatting
drift, no cargo-deny findings. Keep it there - a warning that is tolerated once stops being read.
A lint that cannot be satisfied is allowed where it occurs, with the reason next to it, or excluded in
its config with the reason there; it is never left to warn.

- Rust and Luau files are capped at 500 lines by `scripts/check-file-size.sh`, with no exceptions. A file
  that reaches the cap is split into modules, not exempted (see `crates/lune-roblox/src/instance/` and
  `crates/lune-roblox/src/datatypes/types/cframe/`).
- Every `.luau` file declares its type-checking mode on line 1 (`scripts/check-strict.sh`). `.luaurc`
  already sets strict mode, but a file read without it - copied typedefs, a script run from elsewhere -
  falls back to nonstrict and goes unchecked. `--!nocheck` is for files that cannot be checked, such as
  the Roblox Studio scripts below.

The same gates run in CI (`.github/workflows/ci.yaml`) and before each commit (`lefthook.yml`).

## Settled decisions

- **A hard fork.** Upstream is not merged wholesale. Its open pull requests are taken one by one, with
  the author kept (`Co-Authored-By` when squashed), and adapted to LuneBlox's names.
- **Script folders (`lune`, `.lune`) and the `@lune/*` libraries keep their names**, so Lune code runs
  unchanged. The binary, `_VERSION`, and the home, cache and state directories are `luneblox`.
- **`mlua-sys` is patched** to mlua's own "Bump Luau to 0.740" commit until a crates.io release carries
  it (`[patch.crates-io]` in `Cargo.toml`). mlua's main is not used as a whole: it turns
  fractional-to-integer conversions into errors, which the Roblox datatypes rely on.
- **Luau's fast flags are set as the live Roblox client sets them** (`crates/lune/src/rt/roblox_fflags.rs`,
  generated by `scripts/generate_roblox_fflags.luau`); `LUNE_ROBLOX_FFLAGS=0` keeps Luau's defaults.
- **Releases go to GitHub only**; nothing is published to crates.io.

## Things that look wrong and are not

- **Typedef stubs have unused parameters.** `crates/*/types.d.luau` and `crates/*/types/` describe the
  standard libraries for the editor; every function body is `return nil :: any`. selene skips them and
  luau-lsp checks them.
- **Typedefs are either one file or a directory module.** A library past 500 lines keeps its typedefs in
  `types/init.luau`, requiring its submodules through `@self`. `typedef_submodules()` carries the extra
  files, and `luneblox setup` writes such a library as `<name>/init.luau`.
- **The scheduler's Lua examples use undefined globals.** `crates/mlua-luau-scheduler/examples/lua/`
  runs under Rust examples that inject `sleep`, `spawn`, `defer`, `readFile` and `exit`.
- **`scripts/font_enum_map.luau` and `scripts/physical_properties_enum_map.luau` use Roblox globals.**
  They run in the Roblox Studio command bar to regenerate Rust tables, so they are `--!nocheck`.
- **SHA-3 HMACs go through `SimpleHmac`.** sha3 0.12 no longer exposes a block-level core; the result is
  the same RFC 2104 HMAC, and the test vectors in `tests/serde/hashing` pin it.
- **Duplicate crate versions are allowed** in clippy and cargo-deny. They are all transitive.
- **cargo-deny only sees the six release targets.** Crates that exist only for wasm, such as `stdweb`
  under `rbx_cookie`, are never built and stay out of the checks.

## The prompt trap

`stdio.prompt` does not degrade when stdin is not a TTY - it throws `IO error: not a terminal`, and under
some runners blocks with nothing printed. Anything that prompts must not be reached from a test, a git
hook or CI. `tests/stdio/prompt.luau` is deliberately left out of the automated suite for this reason.

## Commands

| Task | Command |
|---|---|
| Install the toolchain | `rokit install` |
| Install git hooks | `lefthook install` |
| Build | `cargo build` |
| Run the test suite (Rust and every Luau test) | `cargo nextest run --workspace --all-features` |
| Lint Rust | `cargo clippy --workspace --all-targets --all-features -- -D warnings` |
| Type-check Luau | `./scripts/analyze.sh` |
| Lint Luau | `selene .lune crates scripts tests` |
| Check formatting | `./scripts/format-check.sh` |
| Format | `./scripts/format.sh` |
| Check type-checking modes | `sh scripts/check-strict.sh` |
| Check file sizes | `sh scripts/check-file-size.sh` |
| Check English | `sh scripts/check-english.sh` |
| Check dependencies | `cargo deny check` |
| Run all pre-commit gates | `lefthook run pre-commit --all-files` |
| Regenerate the fast flags | `lune run scripts/generate_roblox_fflags` |
| Look at an upstream pull request | `git fetch upstream pull/<n>/head:pr-<n>` |

A Luau test is a script under `tests/`, registered in `crates/lune/src/tests.rs`; a new test file that
is not registered there never runs.
